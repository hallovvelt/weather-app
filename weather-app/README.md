# 🌤 Weather App

A simple and responsive weather application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Real-time weather data via OpenWeatherMap API
- Temperature, humidity, and wind speed
- Dynamic background color based on weather condition
- Animated clouds
- Error handling for invalid city names

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox, animations)
- JavaScript (Fetch API, async/await)
- OpenWeatherMap API

## 🔧 How to Use

1. Open `index.html` in your browser
2. Type a city name in the search box
3. Press **Search** or hit **Enter**
4. Weather data will be displayed instantly

- How to connect to a public API using `fetch()`
- Handling asynchronous JavaScript with `async/await`
- DOM manipulation — updating HTML elements with JavaScript
- CSS animations and dynamic styling
